4. API LAYER (src/api/http.ts)
================================================================================

Base URL: import.meta.env.VITE_API_URL ?? '/api/v1'

apiUrl(path):
  - Strips leading slash from path
  - Returns `${API_BASE_URL}/${path}`
  - Example: apiUrl('/cotizaciones') -> '/api/v1/cotizaciones'

apiFetch(path, init):
  - Calls fetch(apiUrl(path), { ...init, credentials: 'include' })
  - On 401 (if not on /login): redirects to /login + throws
  - Returns Response

axios instance (src/lib/axios.ts):
  - baseURL: API_BASE_URL
  - withCredentials: true
  - Exported as default, currently unused (apiFetch is used everywhere)

7. AUTH FLOW
================================================================================

Login (src/features/auth/Login.tsx):
  - Standalone (no MainLayout)
  - POST /auth/login with { email, password }, credentials: 'include'
  - On success: navigate('/admin')
  - Error display: 401 -> "Correo o contraseña incorrectos"

ProtectedRoute (src/features/auth/ProtectedRoute.tsx):
  - POST /auth/refresh (credentials: 'include')
  - On success: renders children
  - On failure: navigate('/login', { replace: true })
  - Shows spinner while checking

AdminRoute (src/features/admin/AdminRoute.tsx):
  - Wraps ProtectedRoute > Suspense > lazy AdminDashboard

AdminDashboard (src/features/admin/AdminDashboard.tsx):
  - GET /cotizaciones?page=&size=&busqueda=&estado= (paginated)
  - GET /cotizaciones/metricas
  - GET /cotizaciones/exportar?busqueda=&estado= (CSV blob download)
  - PATCH /cotizaciones/{id}/estado?estado=
  - All via apiFetch (credentials included)
  - Estado types: NUEVO, CONTACTADO, COTIZADO, CERRADO
  - Search debounce: 500ms
